IFC_VolumeCalc

Десктопное приложение для офлайн-анализа, подсчета объемов и суммирования атрибутов элементов в BIM-моделях формата IFC (IFC2X3, IFC4, IFC4X3) с формированием конфигурируемой сводной таблицы и экспортом в Excel / CSV.

Возможности

1. Работа 100% офлайн: Никаких подключений к интернету или внешним облачным сервисам.
2. Высокая производительность на больших IFC-файлах (100–1500 МБ):
   - Парсер читает только семантические данные, наборы свойств (`IfcPropertySet`) и количества (`IfcElementQuantity`), полностью пропуская тяжелые 3D полигональные сетки (Geometry Bypass).
   - Это сокращает потребление ОЗУ на 90% и ускоряет чтение.
3. Многопоточность (QThread):
   - Парсинг файла происходит в фоновом потоке с живым индикатором прогресса. Интерфейс никогда не зависает («Не отвечает»).
4. Анализ атрибутов и свойств:
   - Автоматический сбор всех прямых атрибутов (`Name`, `Tag`, `ObjectType` и др.), наборов пользовательских свойств (`Pset_`) и количеств (`Qto_`, `BaseQuantities`).
   - Автоматическое определение типов данных (Число, Текст, Да/Нет) и единиц измерения.
5. Подсчет сумм и статистика:
   - Общее число элементов.
   - Число и процент элементов с атрибутом (зеленый бейдж).
   - Число и процент элементов БЕЗ атрибута (красный бейдж дефектов модели).
   - Для числовых свойств: автоматический подсчет СУММЫ (площадь, объем, длина, вес, количество и т.д.), среднего, минимума и максимума.
6. Гибко настраиваемая сводная таблица:
   - Группировка: По классам IFC (`IfcWall`, `IfcSlab`...), По этажам/уровням (`Storey`), По типам элементов (`IfcTypeProduct`), либо Детальный реестр.
   - Сортировка по любому столбцу (по сумме, числу элементов, количеству пропусков).
   - Фильтрация: быстрый поиск в таблице, переключатели «Только с атрибутом» / «Только БЕЗ атрибута».
7. Вкладка поиска дефектов модели (QA/QC):
   - Просмотр точного списка элементов, у которых отсутствует выбранный атрибут, с отображением `GlobalId` (GUID), имени, класса и этажа.
   - Копирование GUID в буфер обмена в один клик для поиска в Revit, Navisworks, Solibri или Renga.
8. Экспорт отчетов:
   - Excel (.xlsx): двухстраничный форматированный отчет (сводная таблица с цветной шапкой и итоговой строкой + отдельный лист с реестром пропущенных элементов).
   - CSV: выгрузка в формате UTF-8 с разделителем точка с запятой для корректного открытия в Excel.
9. Современный UI:
   - Поддержка Тёмной (по умолчанию) и Светлой темы оформления с переключением на лету.
