# IFC_VolumeCalc 3D Viewer

Интерактивный 3D-просмотрщик BIM-моделей формата IFC (IFC2X3, IFC4, IFC4X3) с анализом атрибутов, подсчетом объемов, селектором элементов в 3D и инспектором свойств.

---

## Возможности

1. **3D Визуализация (VTK + PyVista + OpenCASCADE)**:
   - Высокоскоростная многопоточная триангуляция через C++ ядро `ifcopenshell.geom`.
   - Отображение реальных цветов и прозрачностей материалов САПР (`IfcSurfaceStyle`).
   - Режимы отображения: тонированный с ребрами (Shaded with edges), полупрозрачный рентген (X-Ray), сечение и каркас.
2. **Интерактивный выбор элементов (3D Raycast Picking)**:
   - Клик левой кнопкой мыши по любому элементу в 3D сцене подсвечивает его ярким неоновым контуром.
   - В окне **«Свойства элемента»** сразу открывается подробный паспорт: GUID, класс, имя, этаж, тип элемента, все наборы свойств (`Pset_*`) и количественные параметры (`Qto_*`).
   - Кнопка «📋 Копировать GUID» в один клик.
3. **Двусторонняя синхронизация с аналитикой**:
   - При выборе строки в сводной таблице или в реестре дефектов («Элементы без атрибута») камера в 3D автоматически центрируется на элементе, а сам элемент подсвечивается.
   - Кнопка **«⚠️ Выделить дефекты в 3D»** окрашивает элементы без выбранного атрибута в красный цвет, делая остальные полупрозрачными.
   - Кнопка **«Изолировать»** скрывает все остальные элементы модели для детального осмотра.
4. **Аналитический расчет объемов и сумм**:
   - Карточки KPI: общее число элементов, найдено с атрибутом (шт. и %), пропущено (шт. и %), итоговая сумма значений, среднее, мин/макс.
   - Гибкая сводная таблица с группировкой по классам IFC, по этажам, по типам или детальным реестром.
   - Экспорт отчетов в Excel (`.xlsx`) и CSV.

---

## Запуск 3D Viewer

```bash
python viewer/main.py
```
Или с автоматическим открытием файла модели:
```bash
python viewer/main.py "path/to/model.ifc"
```
